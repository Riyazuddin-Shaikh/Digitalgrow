# Preface Communications

A high-end, dark-themed architectural portfolio and digital studio web application built with modern web technologies.

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Animations:** GSAP (GreenSock Animation Platform)
- **Styling:** CSS3 (Custom responsive layout & dark aesthetics)
- **Deployment:** GitHub Pages (`gh-pages`)

## Key Features

- **Custom Preloader:** Smooth introductory loading sequence with lifecycle-safe scroll position handling.
- **Automated Lead Generation Popup:** Appears 5 seconds after page load, featuring a sleek dark modal, mandatory mobile number validation, optional email/message inputs, success state feedback, and 4-second auto-dismissal.
- **Curated Gallery & Banner:** Showcases minimalist architectural masterworks and high-resolution design projects with fluid scroll-triggered animations.
- **Responsive UI/UX:** Tailored for seamless performance across desktop and mobile viewports.
